## ⚡ Quick Start

### 1. Backend (API)

```bash
cd sysmed-api
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

### 2. Frontend (Web)

```bash
cd sysmed-web
npm install
npm run dev
```

### 3. Acesso

-   **API**: http://localhost:8000
-   **Web**: http://localhost:5173
